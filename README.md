# Tasks Widget

Windows 바탕화면에서 **Google Tasks(할 일 목록)** 를 바로 보고 관리할 수 있는 데스크톱 위젯입니다.

A small Windows desktop widget for viewing and managing your Google Tasks.

## 다운로드 / Download

- **최신 버전 / Latest release:** <https://github.com/tjdwns4570/tasks-desktop-widget-downloads/releases/latest>

이 저장소는 위젯 설치 파일 배포용입니다. 릴리스 페이지에서 최신 버전을 내려받아 설치하세요.
This repository hosts release downloads only. Get the latest build from the Releases page.

## 주요 기능 / Features

- Google 계정으로 로그인하여 Google Tasks 목록과 할 일을 바탕화면에서 확인
- 할 일 추가, 완료 처리, 수정
- 별도 서버 없이 사용자 PC에서 Google API와 직접 통신
